# 运行配置参考

`agents/`为快照时当前system正文；`runtime.json`是对应预算、标志、少量设置和工具绑定。它们帮助复核“模型被什么指令约束”，不包含模型profile ID、API Key或生产任务内容。

这些文件不会被启动程序自动导入，也不是生产数据库恢复。应通过本地ARTEX管理界面按需应用；经验部分优先使用`extensions/experience/installer.py`，避免协作段重复。当前模型和触发器可能随后由管理员修改，所以配置参考不能代替实时状态。

硬约束在Go/Python代码中，提示词变更无法自动突破planner或链路复盘白名单。通用ChatAgent中的经验整理/检索角色尚没有与链路复盘相同的全程硬工具隔离。
